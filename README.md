# Forum + Admin Panel

## Запуск
1. Установите Python 3.10+.
2. `pip install -r requirements.txt`
3. `python app.py`
4. Откройте `http://127.0.0.1:5000`

## Администратор по умолчанию
- Логин: `admin`
- Пароль: `admin123`

После первого входа обязательно смените пароль и `SECRET_KEY`.

База `forum.db` создаётся автоматически.
